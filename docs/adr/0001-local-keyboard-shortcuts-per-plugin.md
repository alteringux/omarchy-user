# Local keyboard shortcuts per plugin, not reserved global meanings

Across the custom plugins, the same key means different things: `X` cancels a countdown, skips a Pomodoro phase, and clears dashboard notes; `Enter` confirms in some panels and does nothing in others. We considered reserving a fixed meaning per key across every plugin (`X` always cancels/undoes, `Enter` always confirms) so a future plugin author could look up the reserved set instead of choosing per-panel.

We chose local meanings instead: each plugin's panel picks whatever key mapping is most natural for its own domain and documents it in a hint row at the bottom of the panel. The only project-wide invariants are (1) `Esc` always closes the panel, and (2) every panel with local shortcuts shows a hint row naming them. Reasoning: countdown's "X: cancel" and pomodoro's "X: skip" are both already coherent as *shapes* ("the secondary destructive-ish action") even though the words differ — forcing identical wording across genuinely different domains (a timer vs. a phase cycle vs. a notes list) would read as more rigid than useful, especially with a growing, hobby-driven plugin roster where each plugin's domain varies a lot.
