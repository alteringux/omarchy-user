- [x] **A mood ring on the bar icon** (Model.js + BarWidget.qml) — `Model.moodFace(mood)` maps the computed mood to a face (ecstatic/content → 🙂, meh → 😐, hungry → 😋, grumpy → 🙁; asleep and unknown → none, since the 󰒲 sleep glyph already holds that slot) and `BarWidget.qml` appends it after the pet glyph in `displayText`, so the pet's state is readable without opening the panel. Tests: every mood gets its face, asleep/unknown stays blank.
- [x] **Time-of-day chatter** (Model.js) — pure `timePeriod(hour)` buckets 0-23 into morning/afternoon/evening/lateNight (null out of range), and `pickTimeLine(hour, seed)` picks from shared banks in the `CLIPPY_TIPS`/`ZOOM_LINES` style: one pool the caller wraps in `pet.voice()`, so all pets share it. Wired into `pickAmbientLine` below battery/idle/mood: ~1 in 3 ambient seeds (`seed % 1000 < 300`) with a valid `hourValue` (new `hourValue` in the ambient context from BarWidget → Pet) takes the time branch, else it falls through to the generic tip. Tests: bucket boundaries, out-of-range/missing → null, seeded in-bank picks, the 1-in-3 seed gate, the missing-hour fallthrough, and battery/idle/mood still outranking it.
- [x] **Level-up praise line** (Model.js + Pet.qml) — the existing `levelInfo`/`didLevelUp`/`pickLevelUpLine` logic (a `LEVEL_UP_LINE` template with `{level}`/`{title}` slots, capped at the last `LEVEL_TITLES` tier, wrapped in the pet's voice) is now wired into `Pet.qml`'s `onStateChanged`: a new branch after the achievement branch and before the poke/feed/play branches says the praise line, sparkles, and bounces when the derived level actually crosses a threshold — so the moment can't be swallowed by the poke reaction. Tests: `didLevelUp` fires only on a real threshold cross and counts feeds/plays, and `pickLevelUpLine` interpolates level+title in the pet's voice, clamps 0/missing to 1, and caps the title at the last tier.
- [x] **Snore bubbles while asleep** (Pet.qml) — a `snoreTimer` running while `liveState.asleep` spawns a 💤 (or a small `z`) above the head every ~1.4-2.2s, drifting up and fading out via the shared `particleComponent`. Complements the static corner 💤 badge; pure animation, no model change.
- [x] **Seasonal events** (Model.js + BarWidget.qml + Pet.qml + Panel.qml) — pure `seasonalEvent(month, day)` matches exact dates for New Year, Valentine's Day, Halloween, and Christmas, returning `{ id, name, glyph }` or null; `pickSeasonalLine(pet, month, day, seed)` picks from a shared per-event bank (`SEASONAL_LINES`) wrapped in the pet's voice, or "" when no event is active. Wired into `pickAmbientLine` between mood and time-of-day: half the seeds (`< 500`) take the seasonal branch when an event is active, falling through cleanly to time-of-day/generic when not. `BarWidget.qml` exposes `monthValue`/`dayValue` (derived from `nowMs`); `Pet.qml` passes them in the ambient context; `Panel.qml` shows the event glyph + name in the PanelHead meta when active. Tests: each holiday date matches, non-holiday/missing/invalid → null, voiced in-bank picks, the half-seed gate, the no-event fallthrough, and battery/idle/mood still outranking it.
